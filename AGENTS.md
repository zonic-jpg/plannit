## Cursor Cloud specific instructions

**plannit** is a Next.js 16 life-planning web app (TypeScript + Tailwind CSS 4). Data is persisted in the browser's localStorage.

- **Install deps:** `pnpm install`
- **Dev server:** `pnpm dev` (runs on port 3000)
- **Lint:** `pnpm lint`
- **Build:** `pnpm build`
- Refer to `README.md` for the full script table.

No external services (databases, APIs, Docker) are required. The app runs fully client-side.
